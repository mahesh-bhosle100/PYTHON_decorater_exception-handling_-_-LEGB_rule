Python Decorator 

A decorator is a powerful feature in Python used to modify or extend the behavior of a function without changing its original code.
It works by passing a function as an argument to another function.
Decorators help in writing reusable, clean, and maintainable code.
They are commonly used for logging, authentication, validation, and performance measurement.
Decorators internally use closures.
The @ symbol is a shorthand syntax for applying a decorator.

LEGB Rule 

The LEGB rule defines how Python resolves variable names.
When a variable is accessed, Python searches for it in a specific order.

After that, it looks in the Global scope and finally in the Built-in scope.
This rule is essential for understanding variable scope and closures.
The LEGB rule helps prevent naming conflicts in programs.

Exception Handling 

Exception handling is used to manage runtime errors in a program.

Python uses try, except, else, and finally blocks for exception handling.
Different exceptions handle different types of errors.
Custom exceptions can also be created by the programmer.
